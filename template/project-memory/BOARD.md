# Board

The short, canonical view of unfinished work.

Allowed task statuses: `proposed`, `active`, `blocked`.

Each task requires: `Status`, `Priority`, `Owner`, `Related`, `Summary`, and `Acceptance`.

For shared repositories, prefer `Owner: @github-login` when the responsible GitHub identity is known. `Branch` and `Scope` are optional coordination fields: `Branch` names the task's working branch, and `Scope` is a comma-separated set of repository-relative file or directory prefixes. These fields expose likely parallel-work collisions; they do not lock files or grant repository permissions.
