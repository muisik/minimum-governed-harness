# History

The canonical record of completed or cancelled tasks and their completion evidence.

Allowed task statuses: `completed`, `cancelled`.

Each record requires `Status`, `Related`, `Evidence`, and `Outcome`. Completed tasks require `Completed: YYYY-MM-DD`; cancelled tasks require `Cancelled: YYYY-MM-DD`.

Detailed implementation notes, acceptance proof, test evidence, outcome, and any remaining boundary for completed or cancelled work belong here rather than being duplicated in `NOTES.md`.
